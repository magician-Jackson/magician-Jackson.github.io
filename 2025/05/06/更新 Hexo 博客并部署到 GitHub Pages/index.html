如何更新 Hexo 博客并部署到 GitHub Pages

作为一名 Hexo 博客用户，我经常需要添加新文章或修改内容，并将更新部署到 GitHub Pages。最近，我整理了一套简单的流程，用于更新我的博客（托管在 https://magician-jackson.github.io）。这篇教程分享如何在本地编辑内容、预览效果，并部署到 GitHub Pages，适合初学者和有一定经验的用户。

前提条件

  • 你已有一个 Hexo 项目（例如 ~/myblog），并通过 hexo server 本地测试正常。
  • 博客托管在 GitHub Pages（例如 https://github.com/magician-jackson/magician-jackson.github.io）。
  • 已安装 hexo-cli 和 hexo-deployer-git。
  • 本地环境：Node.js、npm 和 Git 已配置。

步骤概览

  1. 添加或修改文章内容。
  2. 本地预览更新。
  3. 配置部署设置。
  4. 部署到 GitHub Pages。
  5. 验证网站更新。

2. 本地预览更新

在部署前，建议预览内容：

  • hexo clean：清除旧缓存。
  • hexo generate：生成静态文件到 public/。
  • hexo server：启动本地服务器。

访问 http://localhost:4000，检查：

  • 新文章或修改是否显示。
  • 图片和样式是否正常。
