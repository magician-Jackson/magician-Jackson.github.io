在 Ubuntu 上使用 VS Code 编译、运行和调试 C/C++ 程序

Visual Studio Code (VS Code) 是一个功能强大的代码编辑器，适合开发 C/C++ 程序。在 Ubuntu 上，VS Code 需要配置外部编译器和调试工具。本教程将指导你完成安装、配置和使用 VS Code 进行 C/C++ 程序的编译、运行和调试的完整流程。

3. 安装 VS Code 插件

在 VS Code 中安装以下两个插件：

  • C/C++：提供代码补全、语法高亮和调试支持。
  • Code Runner：支持一键编译和运行程序。

操作步骤：

  1. 打开 VS Code，点击左侧活动栏第五个图标（扩展，快捷键 Ctrl+Shift+X）。
  2. 搜索并安装 C/C++（Microsoft 提供）和 Code Runner。
  3. 安装完成后重启 VS Code。
  4. 暂时不要安装其他推荐插件，以避免配置冲突。

5. 调试程序

  1. 打开一个 C/C++ 文件（如 test.c 或 test.cpp）。
  2. 设置断点：点击代码行号左侧，添加红点。
  3. 按 Ctrl+Shift+B 编译程序（运行 tasks.json 中的编译任务）。
  4. 按 F5或者右上角箭头启动调试，VS Code 将使用 gdb 运行程序。
  5. 使用调试工具栏控制程序（步进、继续、停止等）。

额外功能：

  • 按 Ctrl+Shift+B 可单独编译程序（不运行），类似于传统 IDE 的“构建”功能。
